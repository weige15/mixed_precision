# RAMP: Reinforcement Adaptive Mixed Precision Quantization for Efficient On Device LLM Inference

- Authors: Arpit Singh Gautam, Saurabh Jha
- Year: 2026
- Source: https://arxiv.org/abs/2603.17891
- Topic: RL-based per-layer bitwidth assignment for on-device LLM inference

## Key Idea

RAMP uses an off-policy Soft Actor-Critic controller to learn per-layer bitwidth
assignments under a global bit budget. The policy conditions on activation
statistics, weight properties, and structural descriptors, and introduces scale
folding to move activation outlier difficulty into weights.

## Relevance

RAMP is useful for the "importance + hardware budget" formulation. It does not
route each prompt directly, but it does learn a precision policy from features
that include activation statistics and layer structure, then exports allocations
to a practical model format.

## Use For This Project

- Cite as recent RL-style LLM bit allocation under a bit budget.
- Use its feature-conditioned policy as precedent for a learned precision
  predictor.
- Its GGUF export angle is a reminder that final policies should map to an
  existing serving format where possible.
