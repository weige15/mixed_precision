# HAQ: Hardware-Aware Automated Quantization with Mixed Precision

**Authors:** Kuan Wang, Zhijian Liu, Yujun Lin, Ji Lin, Song Han  
**Year:** 2019  
**Venue:** CVPR 2019  
**Source:** https://arxiv.org/abs/1811.08886  
**Official paper PDF:** https://openaccess.thecvf.com/content_CVPR_2019/papers/Wang_HAQ_Hardware-Aware_Automated_Quantization_With_Mixed_Precision_CVPR_2019_paper.pdf

## Key Idea

HAQ frames per-layer bitwidth assignment as a hardware-aware policy search problem. It uses reinforcement learning to choose mixed precision under resource constraints and uses direct hardware feedback, such as latency and energy, rather than only proxy metrics like FLOPs or parameter count.

## Relevance

This is one of the clearest precedents for the user's intuition that precision assignment has an exponential `nCr`/combinatorial search space. HAQ's answer is not brute force: learn or search over a policy using hardware feedback and constraints.

## Connection To Current Project

- Supports adding a measured hardware-cost model to H7.
- Reinforces that optimal precision policies are hardware-specific.
- Suggests resource metrics should be part of the policy-selection loop, not only post-hoc reporting.

## Limitations For This Project

HAQ targets DNN inference rather than LoRA fine-tuning of LLMs. Its search method is useful conceptually, but the labels, constraints, and backend kernels must be adapted to LLM fine-tuning.
