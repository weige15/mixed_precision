# PEQA: Memory-Efficient Fine-Tuning of Compressed Large Language Models via sub-4-bit Integer Quantization

**Authors:** Jeonghoon Kim et al.  
**Year:** 2023  
**Source:** https://arxiv.org/abs/2305.14152  
**Hugging Face paper page:** https://huggingface.co/papers/2305.14152

## Key Idea

PEQA adapts quantized LLMs by updating quantization scales rather than full model weights. This keeps the quantized structure intact and reduces optimizer memory.

## Relevance

PEQA is a useful example of fine-tuning directly in the space of quantization parameters, rather than treating quantization as only pre- or post-processing.

## Connection To Current Project

- Suggests the optimizer could choose which quantization parameters or scales are trainable.
- Provides an alternative to LoRA adapters for adapting a low-bit backbone.
- Reinforces that hardware-backed low-bit fine-tuning may need methods beyond module-level dtype assignment.

## Limitations For This Project

The method changes the adaptation mechanism. It is relevant for future comparison, but it is not the same as the current LoRA fake-int8 perturbation pipeline.
