# FGMP: Fine-Grained Mixed-Precision Weight and Activation Quantization for Hardware-Accelerated LLM Inference

- Authors: Coleman Hooper, Charbel Sakr, Ben Keller, Rangharajan Venkatesan, Kurt Keutzer, Sophia Shao, Brucek Khailany
- Year: 2025
- Source: https://arxiv.org/abs/2504.14152
- Topic: Fine-grained hardware/software co-design for weight and activation mixed precision

## Key Idea

FGMP uses sensitivity estimates based on Fisher-weighted perturbations to choose
which weight and activation blocks should remain higher precision. It also
proposes hardware support for block-granularity mixed precision and on-the-fly
activation precision assignment.

## Relevance

This paper is important because it treats both static weights and dynamic
activations. The activation side is especially relevant when "importance" depends
on the prompt or runtime input rather than only on frozen weight statistics.

## Use For This Project

- Cite for hardware-realistic block-level mixed precision.
- Use as evidence that prompt/input-aware precision likely needs activation
  routing support, not only stored weight bitwidth changes.
- Good comparison point for a method that combines calibration statistics,
  prompt features, and hardware constraints.
