# AWQ: Activation-aware Weight Quantization for LLM Compression and Acceleration

**Authors:** Ji Lin, Jiaming Tang, Haotian Tang, Shang Yang, Xingyu Dang, Song Han  
**Year:** 2023 / MLSys 2024  
**Source:** https://arxiv.org/abs/2306.00978  
**Project:** https://github.com/mit-han-lab/llm-awq  
**Hugging Face docs:** https://huggingface.co/docs/transformers/main/quantization/awq

## Key Idea

AWQ uses activation information to identify salient weights and protect model quality under low-bit weight-only quantization. It is designed to be hardware-friendly and includes CUDA kernel support for fast LLM inference.

## Relevance

AWQ is strong evidence that calibration signals can identify what should be protected when applying low precision. It is not a LoRA fine-tuning method, but it supports the broader thesis that activation-aware sensitivity is a useful predictor.

## Connection To Current Project

- Reinforces the use of activation outlier or activation magnitude features in H7.
- Suggests a policy can be hardware-friendly only if the selected protection pattern maps cleanly to kernels.
- Useful contrast: AWQ protects salient weights/channels, while this project currently ranks modules/paths.

## Limitations For This Project

AWQ is primarily post-training weight-only quantization for inference. It does not directly solve training-time optimizer state, gradient, or LoRA adapter precision.
