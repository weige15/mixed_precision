# SpQR: A Sparse-Quantized Representation for Near-Lossless LLM Weight Compression

**Authors:** Tim Dettmers, Ruslan Svirschevski, Vage Egiazarian, Denis Kuznedelev, Elias Frantar, Saleh Ashkboos, Alexander Borzunov, Torsten Hoefler, Dan Alistarh  
**Year:** 2023 / ICLR 2024  
**Source:** https://arxiv.org/abs/2306.03078  
**Project:** https://github.com/Vahe1994/SpQR

## Key Idea

SpQR compresses most LLM weights to 3-4 bits while isolating outlier weights that cause large quantization errors and storing them separately with higher fidelity.

## Relevance

SpQR is another clear instance of low-bit default plus sparse high-precision exceptions. That is the systems version of the selective rescue idea.

## Connection To Current Project

- Supports measuring local perturbation/error to identify exceptions.
- Suggests a sparse exception representation may be more useful than module-level demotion.
- The project can cite SpQR as evidence that "not all weights/modules deserve the same precision" is an established LLM compression principle.

## Limitations For This Project

SpQR targets inference compression and custom runtime representation. It does not directly handle fine-tuning dynamics or LoRA optimizer state.
